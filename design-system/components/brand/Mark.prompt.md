The bare sunburst symbol, inlined as a data URI — use when you need the mark without the wordmark.

```jsx
<Mark tone="ivory" size={48} />
```

`tone`: `ivory` (on titanium/grey/dark photo) or `titanium` (on off-white/ivory). Pass `src` to swap in a licensed vector once one exists. Prefer `Logo` unless the wordmark is genuinely redundant.
