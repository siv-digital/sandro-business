The system's content container: briefings, phases, list items.

```jsx
<Card href="#" kicker="Sequence" title="The structures that only work early"
  body="Why the estate and tax work has to exist before a buyer puts a number on the company."
  media={workingSession} /* a URL or data URI */ />
```

Hover lifts 3px, darkens the hairline and wipes a keyline across the top edge.
That is the whole gesture. Use `flat` inside already-elevated surfaces. Pass
`children` instead of `title` and `body` for custom internals.
