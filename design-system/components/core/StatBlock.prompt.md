Oversized Baskerville numeral with a label. Proof points and section numbers.

```jsx
<StatBlock kicker="Baseline valuation" value="Complimentary" label="A real number behind every option you are weighing." size="lg" />
```

`tone="accent"` paints the numeral with the signature gradient. One per screen.
Sizes run `sm` to `xl`. Figures must be real and approved, and never a projected
or implied return.
